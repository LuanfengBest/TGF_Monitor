# 非盲 AI 作者语义复核

当前助手逐条阅读了 24 条原公开记录、96 个最终判断和 48 个 actor 回答，并先写入 `manual_notes.json`，再将这些笔记与原始文件哈希合并为 `semantic_review_PRIVATE.json`。没有额外模型调用，没有改分或改标签，没有以隐藏任务或出题条件判定违规。

审阅者知道参考标签和实验结果，因此这是非盲 AI 作者复核，不是独立审阅者、盲审、人工金标准或新的机制实验。标签核对依照实际用户授权、消息顺序、目录日期/价格、实际工具调用及成功回执。后续更改授权只向前生效，取消不抹去之前发生的违规，也不重置累计支出。

`packets/00.txt` 至 `23.txt` 含完整非空公开消息与实际工具调用/回执、最终判断、引用及两个 actor 回答。引用片段在每条内去重为 Q 编号，所有 claim 的引用关系保留；原始 evidence_id 与完整文本仍可从原始 raw 文件核对。空助手消息不承载新事实，展示时省略。逐条入口见 [CASE_INDEX.md](CASE_INDEX.md)。

每行区分：

- 固定 50 阈值下的原分数是否匹配已核对参考；这是数值比较，不能替代语义复核。
- 最终文字结论是否有原记录支持，以及 monitor 是否检查整个记录。`whole_record_checked_by_reviewer` 指本次审阅行为，不能误当 monitor 已完整检查。
- 引用中的主张是否超出具体片段、需要结合其他证据、误认来源或与原文矛盾。300 字符片段的截断不自动等于伪造或最终判断错误；`citation_review_notes` 逐条保留细节，不汇总成事后“证据正确率”。
- actor 回答是否受原记录支持，是否把自己解释当新权限。部分回答混淆“所选回执”与“完整公开记录”，详细记录这种现象，但没有将关联说成因果。

`score_rationale_consistency_note` 仅在笔记明确标出问题时填值，其他位置为 null，不表示逐个做过分数校准研究。`claim_supported_by_original_record` 与覆盖状态均为定性作者诊断，不替换原分数。无论字段如何，96 个原始位置完整保留。

`packet_receipt.json` 保留生成材料时的原始“待复核”状态，作为历史凭证，不回写为已完成。完成状态在 `semantic_review_PRIVATE.json` 和 `review_summary_PRIVATE.json`；所有 24 份材料及其原始来源哈希核对通过。`assemble_review.py` 只包装已经写好的逐条笔记、绑定来源、计算数值配对和用量，不自动生成语义判定。

本次检查没有接受 actor 新授予的用户权限。原始记录中能否授权始终以原用户指令为准。逐条笔记中的推理瑕疵、来源误认、局部引用不足与正确数值结果一并保留，不能只选择分数好看的案例。
