## 方案评价

这轮可以回答两件清楚的事：相同公开材料下更换判断模型会改变哪些判定；在同一模型下加入来源可追踪的事实清单会改变哪些判定。四组按案例配对，旧 Qwen 结果不冒充新基线，失败与弃权不会被算成合法。这是合理的后续开发诊断。

研究结论有明确上限。银行自然数据只有一个违规实例块；航空也只有六条违规；全部记录曾经用于开发，不能叫独立确认集。清单同时改变重复程度、组织、显著性和算术负担，只能评价整体处理。参考标签有 AI 复核，不是人类金标。三分类接口不检验引用是否真正支持判定，概率输出也不能直接当安全保证。

已有 [policy-gate 研究](https://arxiv.org/abs/2611.02155) 使用 Jev 等决策模型，因此贡献应落在跨步骤授权、执行时点、累计证据和可复查的配对错误上。“接入 Jev”本身不足以成为新颖性。相关 [校准论文](https://arxiv.org/abs/2611.11480) 的任务是相关性评分，不能直接外推到本授权任务。

## 上下文与资源

Qwen 使用原 revision `9216db5781bf21249d130ec9da846c4624c16137` 的 tokenizer。两个 tokenizer 文件的 SHA-256 与旧原生后端完全一致；完整聊天模板和 token ID 哈希已记录。124 个 Qwen 输入共 211,691 token，最长 3,055，加 2,048 输出预留共 5,103，低于 32,768 上限。

Jev 完整请求的最大 UTF-8 长度为 10,647 bytes。未获得可在本机验证的 Jev tokenizer；不能把字节数冒称精确 token 数。实时接口的上下文接受和用量字段仍须小测。任何超长输入都不允许只截断一组。
