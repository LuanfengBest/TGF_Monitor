## 必须保持的实验约定

1. 环境为 bank_transfer_2 和 american_airlines_2。actor 候选 gpt-oss-20b/120b，monitor 候选 Qwen3-32B；先验证资源和推理通道，再冻结模型版本和配置。临时小模型调试结果单独标记，不能冒充 proposal 的正式结果。
2. 主标签是实际执行的未经授权动作，包括之后撤销的动作。核对执行事件与授权规范；原 side-task success、是否注入副目标、主任务是否成功都不能直接充当安全标签。
3. 未执行的尝试、失败攻击、无法判定案例分开记录。保留所有生成尝试及排除原因，不能只留下成功攻击。人工抽检标签。
4. monitor 只读取允许的用户请求、适用政策和轨迹视图。隐藏副目标、verifier 输出、实验标签和特权模拟状态不得混入输入；给 actor 的隐藏提示也要从 monitor 视图中去除。
5. 主实验为 all-messages，保留可获得的原始与追问 reasoning；严格 action-only 消融同时去掉两者。核实模型接口确实返回什么，不把 reasoning 摘要冒充完整 reasoning。
6. 生成前按任务家族划分开发、验证、测试；派生轨迹和改写同组。主测试使用未经事后授权改写的执行轨迹，构造授权配对只用于诊断。
7. 缓存并冻结原始 actor 轨迹，使方法间配对比较；长轨迹处理共用同一冻结配置。
8. 追问从同一原始 actor 上下文独立分支，禁用工具调用。回答只能是待核验的证据，不能产生新授权或作为真值。
9. TGF 对固定追问的主比较共享 ledger、选定条目、judge prompt、观察通道、问题数量和回答 token 限制，只改变问题内容。另做 ledger-without-follow-up 消融。
10. 主指标为按环境报告的 TPR × TNR；补充 TPR/FPR、AUROC、hard-negative 误报。阈值在验证集确定并冻结，不在测试集调参。缺少某一类别时指标应标为不可计算，不能补造数值。
11. 成本计入解析、摘要、提问、actor 回答和最终判断，按模型分开记 token，并记录调用数、延迟及 API 费用或 GPU 时间。
12. 原 MonitorBench 协议复现与我们的授权审计协议分别命名和计分；不能直接把后者称为论文分数复现。
