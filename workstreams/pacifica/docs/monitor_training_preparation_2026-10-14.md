# Monitor 微调准备：11 条既有候选的可训练格式验收

2026-10-14。用户确认继续“语义错误 → 合格数据 → 训练预检 → 有限微调对照”。本轮具体工作是将已存在的 5 条 bank pool 与 6 条行程投影 train 意向候选，转成一个统一、简短、可检查的监督合同，并核验真实 tokenizer/template 与 loss mask。B3 和公开解释输出消融保留为可选研究对照，不是训练前置；旧 30 次推理计划不自动执行。

## 本轮范围与边界

最多编译原有 11 例；不生成新任务/轨迹，不改历史标签，不读取 validation 目标作监督，不运行模型或训练，不下载大权重。已有 11 例继续保持 training_eligible=false；格式合格不等于训练数据充分或模型已经改善。先冻结候选来源、代码、输出合同与预算，再唯一一次导出正式候选包。原详细审核保留在 sidecar，只向模型提供公开用户请求/政策/严格因果消息、目标事件 ID 与所有例子相同的工具效果合同。输入中禁止 execution_facts、参考标签、私有故障状态或后续消息。

目标包含执行/授权/越权三字段、原文定位、简短必要条件检查和依据，不训练模仿 actor 的自述或审核者的内部思考。来源指针由校验器取回原文；它只证明定位/来源，不能自动证明语义正确。压缩必须保留技术失败与授权分离、unknown/null，以及先前实际成功/失败效果的区别。全部为非盲 AI 候选；本轮无独立双审，expert_annotation 已遇用量限制，主 agent 负责整理和核查。

## 格式与技术验收

沿用已固定 Qwen/Qwen3-32B 修订 9216db5781bf21249d130ec9da846c4624c16137 的 tokenizer 与官方 chat template，CPU 编译可使用现有 tokenizers/Jinja，不安装训练栈。拟定 future HF 对照为同修订/量化/backend/模板，adapter 关闭/启用唯一权重因素；旧 Ollama GGUF 成绩只留历史。为监督公开简短答案，编译选择 enable_thinking=false，固定空 thinking 前缀；该设置也必须用于未来未训练对照，不能归因于 LoRA 的效果包括切换模式的收益。

对完整 chat 序列计数；只为目标 JSON 与结束 token 设置 loss，其余 prompt/用户轨迹/空 thinking 前缀及 padding 全部 -100。若目标过长、模板不匹配、边界跨 token 或任一证据指针无法绑定因果来源，停止导出，禁止截断或静默丢样本。测试覆盖未来/私有字段污染、错误事件绑定、越权参考来源、unknown 被改 safe、拆分污染、loss mask 以及长度上限。

## 资格决策与下一步

输出逐项资格报告，而非单一人为批准标记：来源完整性、因果边界、目标三字段一致性、证据绑定、split、长度/loss、标注独立性与覆盖、独立评估、同底座权重与资源预检。现有样本仅两个相关训练家族，不能支持广泛泛化；最终未见测试仍缺。训练基础设施和显存/梯度结果仍未完成。

完成本地阶段后保留可复用的数据包与受阻项，只有明确的数据和资源门槛通过才开展一批真实梯度预检；预检不是有效性训练。实际微调另冻结小预算，必须先有同一 HF 底座未训练对照；不在旧 validation 上反复挑 prompt，不将其错例改写进 train。连接恢复前不能声称 Bouchet 队列为空或训练已跑。

本轮 CPU 数据阶段完成后若发现训练资格仍受缺失独立数据约束，给出具体缺口和有限补齐方案；不无限创建新家族、模型排行榜或文件。训练门槛不能为了得到一次成功运行而取消。
